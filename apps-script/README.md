# Gmail → Google Sheets 受信監視

このフォルダのコードは、提出サイトが作るメールを受信し、スプレッドシートへ記録するApps Scriptです。VercelではGmailを読めないため、監視処理はGoogleアカウント側で動かします。

## 初回セットアップ

1. Google Sheetsで新しい提出管理表を作成する。
2. Google Apps Scriptで新規プロジェクトを作り、`Code.gs` と `appsscript.json` をコピーする。
3. プロジェクト設定 → スクリプト プロパティに `SPREADSHEET_ID` を設定する。値は作成したスプレッドシートURLの `/d/` と次の `/` の間にあるID。
4. 任意で `ALLOWED_SENDER_DOMAIN` に学校メールのドメイン（例: `example.ac.jp`）を設定する。空欄なら送信元ドメインを限定しない。
5. エディタから `setupSubmissionDesk` を一度実行し、Googleの権限を承認する。

この実行で管理シートを作成し、`scanSubmissionMailbox` を10分ごとに動かすトリガーを作ります。

## メール形式

件名:

```text
【WEB提出】PBL-01｜学籍番号｜氏名
```

本文の先頭:

```text
URL: https://提出したサイトのURL
```

## 運用先シート

| シート | 用途 |
| --- | --- |
| `PBL課題一覧` | 課題の表示・受付状態を管理 |
| `提出一覧` | 同じ課題ID＋学籍番号は上書きし、再提出回数を加算 |
| `要確認` | 件名・URL・送信元ドメインが不正なメール |
| `_受信台帳` | 同一メールを二重処理しないための台帳 |
| `_障害ログ` | 実行エラーの記録 |

課題を追加する場合は `PBL課題一覧` へ行を加え、フロントエンドの `app/src/content.js` にも同じ課題IDを追加してください。
